# 頌缽初階課程網站

兩日頌缽初階課程招生頁，包含課程介紹、日期時間、地點費用、兩日課表、師資與 Google 表單報名區。

## 網站結構

- `index.html`：網站原始頁面
- `styles.css`：網站樣式
- `assets/`：網站圖片素材
- `dist/`：可直接部署的靜態網站版本

## GitHub Pages

若要用 GitHub Pages 發布，可以將 `dist/` 內的內容作為發布來源，或把根目錄的 `index.html`、`styles.css`、`assets/` 放在 repository 根目錄。
